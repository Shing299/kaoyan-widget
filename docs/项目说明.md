# 考研单词 · 桌面小组件 —— 项目说明

> 包名 `com.kaoyan.widget`　当前版本 **v1.3**（versionCode 7）　minSdk 26 / targetSdk 34
> 仓库：<https://github.com/Shing299/kaoyan-widget>　许可证：MIT

---

## 一、这是什么

一个在 Android 手机上运行的「**考研英语单词定时推送**」应用，由一个 WebView 界面、一个常驻前台服务、
一个桌面小组件和若干闹钟组成。核心思路是：

> 按距离初试的天数，自动把整本词表摊到每天，然后在你自己设的时段里**分批推送**；
> 用手机时还会以**悬浮弹幕**的形式把单词从屏幕上划过。

它不联网、不上传任何数据，学习进度全部保存在本机 `/data/data/com.kaoyan.widget/files/state.json`。

## 二、功能一览

### 2.1 每日单词推送

- 到点推送一批 **5 个**单词，通知栏弹出「考研单词 D19 90/170」这样的标题 + 单词列表。
- 推送时段可自定义（默认 `08:00–22:00`），当天剩余批次会在该时段内**随机摊开**，不会整点齐发。
- 桌面小组件同步显示今日进度。
- 一天的计划推完就停，不会把明天的词提前推。

### 2.2 学习弹幕（悬浮窗）

- 使用手机时，从屏幕**右侧向左**划过一条「单词 + 释义」，用手机的任何界面都能看到。
- **全天生效**，不受推送时段限制（推送时段只管通知批次）。
- 频率按 **个/秒** 自定义，**亮屏 / 熄屏分别独立**（熄屏默认 `0` = 不弹），用**分档滑条**调：
  `0（不弹）/ 0.05 / 0.1 / 0.2 / 0.5 / 1 / 2`。
- 样式可调：字体（默认 / 衬线 / 等宽）、字号、颜色、加粗；文字用描边阴影，任何背景上都可读。
- **多条并存**：最多 12 条，每条独占一条纵向「泳道」，绝不复用，互不压字。
- **与推送联动**：每次推送一批单词时，**这一批词也会按同样顺序以弹幕划过**（批次优先，最多 2.5 秒一个），
  播完再回到设定频率随机弹 —— 通知里看到的和弹幕里看到的是同一批词。

### 2.3 深色模式

全部界面（含设置页与对话框）自动跟随系统深浅色。

### 2.4 界面结构

底部 **Dock** 两个入口：

| 入口 | 作用 |
|---|---|
| 🏠 今日单词 | 在主页时 = 回到顶部；在设置页时 = 回主页 |
| ⚙ 设置 | 打开设置页（初试日期 / 词库 / 推送时段 / 弹幕 / 快捷操作） |

「回到顶部」是 Dock 上方的悬浮圆钮，**只在页面不在顶部时出现**，滚回顶部自动隐藏。

## 三、使用

### 3.1 首次使用

1. 打开 App → 申请通知权限。
2. App 会引导开启「自启动 / 后台运行」与「悬浮窗」权限（都用系统设置页，App 只负责跳转）。
3. 在设置页填**初试日期** → 点「保存并开始」。日期一旦确定，系统会反推每日需要新学的词量。

### 3.2 设置项

| 设置 | 说明 |
|---|---|
| 初试日期 | 决定剩余天数与每日新学量；**只有日期真的变了才会重排当天计划** |
| 词库 | 内置 5398 词；可导入自定义 `txt`（`#` 注释，空格/逗号/分号分隔），也可一键恢复内置 |
| 每日推送时段 | 通知批次的起止时间，默认 `08:00–22:00` |
| 学习弹幕 | 开关、亮屏/熄屏频率滑条、字体/字号/颜色/加粗 |
| 快捷操作 | 「立即推送一批」（立刻发通知 + 弹幕）、「刷新数据」 |

### 3.3 需要的权限

| 权限 | 用途 |
|---|---|
| 通知（POST_NOTIFICATIONS） | 单词推送通知 |
| 悬浮窗（SYSTEM_ALERT_WINDOW） | 学习弹幕 |
| 精确闹钟（SCHEDULE_EXACT_ALARM） | 按时推送；未授予会退化为系统批量唤醒（可能延后） |
| 前台服务 / 开机自启 | 保持推送调度与弹幕服务存活 |

## 四、工作原理

### 4.1 学习计划算法

```
剩余天数 daysLeft = 初试日期 - 今天（至少 1）
每日新学 dailyNew = ceil((词库总数 - 已引入词数) / daysLeft)，夹在 1..300
复习上限 reviewCap = max(40, dailyNew)
```

**记忆曲线**：每个词在 `cards` 里记 `[阶段, 下次该复习的天序号]`，阶段对应 `INTERVALS = {1,2,4,7,15}`（天）。
首次引入（新词或复习词）记阶段 0、`dueDay = 今天 + 1`；之后每次复习阶段 +1，间隔顺延；背完 5 个阶段记 `INF`（不再到期）。

**当天计划**：到期复习词按「阶段小优先 → 逾期久优先」取前 `reviewCap` 个，加上按种子洗牌顺序取的 `dailyNew` 个新词，
整体再打乱成 `plan`。推送时从 `plan_pos` 顺序取，每批 5 个。

### 4.2 推送调度

- `Scheduler.schedule()` 用 `AlarmManager` 的 `RTC_WAKEUP` 精确闹钟，把剩余批次**随机摊在剩余时段**里（最多 60 个）。
- 闹钟只表示「醒来推下一批」，**不绑定具体哪批**，所以每推一次不需要重排闹钟。
- 当天计划推完后撤销剩余批次闹钟（保留每日 `ROLL` 闹钟），避免无效唤醒。
- 开机广播 / 每批推送都会顺带 `BotService.sync()` 一次，服务被杀后可自愈。

### 4.3 弹幕渲染

- 每个弹幕是一扇 `TYPE_APPLICATION_OVERLAY` 窗口，**全屏宽**（避免平移出窗口被裁），
  文字用视图自身的 `translationX` 从「屏幕右侧外」平移到「文字完全移出左侧」。
- **泳道**：可用高度取屏幕 12%~74%，按字号自适应分成最多 12 条泳道；
  一条弹幕占一条，**没有空泳道就放弃这一条**（宁可少弹，也不叠字）。
- **动画**：所有在飞弹幕**共用一条固定帧间隔的循环**（约 30fps 目标 / 实测 42fps）。
  不用 `ViewPropertyAnimator` —— 它跟 Choreographer 走，在 120Hz 屏上会跑到约 91fps，
  同屏 1 条弹幕就吃掉约 30% 单核；改共用循环后降到约 18%。

  | | 帧率 | 动画期间 CPU |
  |---|---|---|
  | 逐条 `ViewPropertyAnimator` | ~91 fps | ~30% 单核 |
  | 全局共享循环 | ~42 fps | ~18% 单核 |
  | 弹幕关闭（不轮询） | 0 fps | **0.00%** |

- **选词**：随机词池 = 今日计划内的**复习词 ×3** + 今日计划内的**新词 ×1** + 「已到期但被 `reviewCap` 挤出计划」的复习词 ×3；
  计划尚未生成时才退回全词库。词表只在首次懒加载一次。

### 4.4 服务

只有一个常驻前台服务 **`BotService`**（`foregroundServiceType="dataSync|specialUse"`），
同时负责推送调度与学习弹幕，通知栏只保留**一条**常驻通知（id 1000）。
弹幕开关只控制「画不画」，不再单独起停服务。

## 五、数据与状态

`/data/data/com.kaoyan.widget/files/`：

| 文件 | 内容 |
|---|---|
| `state.json` | 全部状态（见下表） |
| `history.jsonl` | 每批推送的历史记录（时间、标题、新/复数量、单词列表） |
| `words_custom.txt` | 导入的自定义词库（存在时优先于内置） |

`state.json` 主要字段：

| 字段 | 含义 |
|---|---|
| `exam` | 初试日期 `yyyy-MM-dd` |
| `seed` | 词库洗牌种子 |
| `day0` / `day` / `plan_day_no` | 起始日 / 计划所属日 / 计划的天序号 |
| `plan` / `plan_pos` | 当天计划（`[词索引, 0新/1复]` 数组）与已推到的位置 |
| `cards` | SRS 记忆卡：`词索引 → [阶段, 下次复习天序号]` |
| `push_start` / `push_end` | 推送时段 `HH:mm` |
| `danmaku_on` | 弹幕总开关 `"1"/"0"` |
| `danmaku_rate_on` / `danmaku_rate_off` | 亮屏 / 熄屏频率（个/秒） |
| `danmaku_size` / `danmaku_color` / `danmaku_font` / `danmaku_bold` | 弹幕样式 |

## 六、构建

依赖：`aapt2`、`javac`(JDK17/21)、`d8`、`zipalign`、`apksigner`、`python3`，以及 Android SDK 的 `android.jar`。

```bash
export ANDROID_JAR=$HOME/sdk/ex/android-34/android.jar
export KS=/path/to/your.jks KS_PASS=你的口令 KEY_PASS=你的口令
bash build.sh          # 产物 out/app.apk
```

流程：`aapt2 compile/link → javac → d8 → 注入 classes.dex → zipalign → apksigner`。

> ⚠️ 本项目使用的 d8 版本对**匿名内部类**会 NPE，所有 `Runnable` / `BroadcastReceiver` / 监听器
> 一律写成**命名静态内部类**。
> 另外部分手机的清理功能会把 PNG 改名成 `.trashed-<时间戳>-<原名>` 扔进回收站，
> 导致 `aapt2 link` 报资源找不到；`build.sh` 已内置自动还原。

## 七、项目结构

```
kaoyan-widget/
├─ AndroidManifest.xml
├─ build.sh                  # 构建脚本（密钥由环境变量传入，仓库不含密钥）
├─ assets/words.txt          # 内置考研词表（5398 词）
├─ docs/                     # 本说明 + 截图
├─ res/                      # 资源（布局 / 图标 / 字符串 / 小组件配置）
└─ src/com/kaoyan/widget/
   ├─ MainActivity.java      # 入口（WebView 容器）
   ├─ HtmlView.java          # 全部界面（主页 / 设置页的 HTML 生成）
   ├─ Bridge.java            # JS ↔ 原生桥
   ├─ Engine.java            # 计划推算 / 记忆曲线 / 推送
   ├─ Words.java             # 词库加载（内置 / 自定义）
   ├─ Store.java             # 状态与历史读写
   ├─ Scheduler.java         # AlarmManager 调度
   ├─ Notifier.java          # 通知
   ├─ WidgetProvider.java    # 桌面小组件
   ├─ BatchReceiver.java     # 闹钟回调（推送 + 心跳）
   ├─ BootReceiver.java      # 开机自恢复
   ├─ BotService.java        # 唯一的前台服务（推送 + 弹幕）
   ├─ DanmakuOverlay.java    # 弹幕悬浮层（泳道 / 动画 / 选词）
   └─ Perms.java             # 权限申请与首次启动引导
```

## 九、隐私与安全

- **不联网、无账号、无统计**，所有数据只在本机。
- 仓库**不含**签名密钥、口令、Token 或任何用户数据（`.gitignore` 已排除 `*.jks`、`state.json`、`history.jsonl` 等）。
- 需要「悬浮窗」权限是因为弹幕功能，需要「精确闹钟」是为了按时推送 —— 都可随时在系统设置里撤销。

## 十、已知限制

- 弹幕弹的是**词表里抽出的词**，不判断你是否已经背熟；复习词权重更高只是概率上的倾斜。
- 推送时段结束后当天不再推送，剩余词数会累积到次日计划。
- 弹幕在下拉通知栏、负一屏等少数系统界面上可能不显示（系统悬浮窗策略）。
- 超长释义在弹幕里会一次性划过去，同一时刻只能看到一部分。
